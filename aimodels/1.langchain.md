### Introduction
- **LangChain** is a toolkit which connects the LLM to long-term memory, tools and workflows -> turns raw model output into behavior
- LLMs are stateless with each run, so each simple prompt becomes a structured prompt
- The LLM is the core reasoning unit of LangChain
- Core capabilities
  - Build **chains** that connect multiple steps together into a logical flow (e.g. prompt -> LLM -> output parser)
  - Create **agents** that decide what to do next (e.g. plan, act, observe, reflect, repeat loop)
  - Add **memory** to remember past interactions (e.g. stores key facts, enables continuity, with buffer/window/summary/entity)
  - Use **retrieval** to ground responses in your own data
- Real world examples
  - AI tutors which guide students, customer support bots, building workflow agents

### Getting started with LangChain
To install Py packages which allow LC to connect to OAI
```py
  pip install langchain langchain-openai
# Import components to build LC apps
  from langchain_openai import ChatOpenAI # connects to language models
  from langchain_core.prompts import PromptTemplate # creates reusable prompt structures
  from langchain_core.output_parsers import StrOutputParser # convert responses to plain text
```

### Workflow overview, LCEL
1. User input
2. Prompt template: Reusable structure which formats user's input into instruction model can understand. Combines a fixed instruction with placeholder, which is filled at `runtime`.
3. LLM: Core reasoning engine, which reads formatted prompt
4. Output parser: Explanation by model is in raw text form, and parser converts it into clean, plain text
5. Final output: Formatted explanation
